# Video Conferencing Platform

A real-time video conferencing web application that enables users to communicate through video, audio, chat, and screen sharing directly from the browser.

## 🚀 Features

- 🎥 Real-time video and audio communication
- 🔐 User authentication
- 🏠 Meeting rooms
- 💬 Real-time chat
- 🖥️ Screen sharing
- 🎙️ Audio and video controls
- 📡 WebRTC-based peer-to-peer communication
- 🔄 Socket.IO for real-time signaling and communication
- 🌐 STUN server configuration for establishing peer connections
- 📊 Call/meeting history

## 🛠️ Tech Stack

### Frontend
- React.js
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- Socket.IO

### Database
- MongoDB

### Communication
- WebRTC
- STUN Server

## 🏗️ Project Architecture

The application uses **WebRTC** to establish peer-to-peer audio and video connections between users. **Socket.IO** is used for real-time signaling and communication, while **MongoDB** stores user and application data.
